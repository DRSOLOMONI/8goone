# 8Goone - Solana Gaming Token Scanner

A professional real-time AI-powered scanner for gaming-related tokens on Solana with web dashboard and Gmail notifications.

## Features
- Real-time monitoring of new Raydium pools
- Gaming token detection (AI keyword + metadata analysis)
- Beautiful Streamlit web dashboard
- Secure Gmail alerts
- Configurable filters

## Quick Start
1. Clone the repo
2. `pip install -r requirements.txt`
3. Setup `.env` and Gmail credentials
4. Run `streamlit run dashboard.py` for web UI
5. Or `python scanner.py` for headless mode

## Deployment
Deploy dashboard easily on Streamlit Cloud or Railway.
